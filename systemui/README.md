# SystemUI integration

This area tracks source-level changes required for a cohesive iDroid system experience.

Planned work:

- Status bar and icon treatment.
- Quick Settings / Control Centre presentation.
- Notification shade cards and grouping.
- Keyguard and lock-screen styling.
- Volume and brightness dialogs.
- Animation and blur performance fallbacks.

SystemUI is part of the Android platform. Changes must be developed against a pinned Android 14 source revision and built with the matching platform toolchain. Do not copy patches across Android versions without review.

No SystemUI source or patches are present yet.
